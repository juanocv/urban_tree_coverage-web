Local obrigatório

Geocodificado pela API. Ignorado quando latitude e longitude são informadas.

Graus decimais. Latitude entre −90 e 90, longitude entre −180 e 180.

Estratégia de vistas obrigatório
Captura opcional

0° = norte, 90° = leste.

Tipicamente a orientação da rua. As demais vistas derivam dela.

Negativo aponta para baixo, positivo para cima.

Ângulos menores aproximam a cena.

LARGURAxALTURA, máximo 4096 px por lado.

Plano de vistas opcional

Somados à direção de referência. Separe por vírgula.

Distribuídas uniformemente em 360°.

Direções planejadas

0° · 90° · 180° · 270°

Executando a API localmente

Este site é estático e não processa imagens.

python -m pip install -e ".[api,ml]"
uvicorn urban_canopy.webapi:app --host 127.0.0.1 --port 8000

Depois libere a origem deste site no CORS da API:

UC_API_CORS_ORIGINS=https://juanocv.github.io

Um navegador em HTTPS só aceita chamadas HTTP para localhost.

Para acessar de qualquer lugar, ligue a autenticação e exponha a API por HTTPS:

UC_API_TOKENS=$(python -c "import secrets; print(secrets.token_urlsafe(32))")
cloudflared tunnel --url http://127.0.0.1:8000

Cole o token no campo Token de acesso.

A API chama uma API paga do Google a cada requisição e não tem autenticação.
